# Roadmap

## Phase 1: harden core dataframe semantics

Strengthen DataFrame, Series, Schema, DType, NULL, errors, grouping, joins, reshaping, windows, I/O, and tests. The current alpha covers these surfaces with pure-Python behavior, but additional compatibility and stress tests are still needed before a beta stability promise.

## Phase 2: practical data workflows

Improve CSV/JSON inference, SQL integration, categorical data, datetime workflows, richer indexes, and migration tools.

## Phase 3: performance and backends

Add NumPy and Arrow backends, optimize joins and group-bys, and introduce compiled kernels where justified.

## Phase 4: ecosystem maturity

Expand documentation, examples, benchmarks, compatibility suites, packaging, and third-party integrations.

## Phase 5: large-scale adoption and compatibility maturity

Focus on stability, deprecation policy, performance predictability, interoperability, and community governance.
