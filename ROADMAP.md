# Otter Roadmap

## Phase 1: Complete core dataframe semantics

Stabilize DataFrame, Series, dtype, null, schema, grouping, joins, reshaping, windows, lazy planning, I/O, and tests.

## Phase 2: Practical data workflows

Improve user ergonomics, richer time-series tools, SQL support, categorical data, nested data, and migration recipes.

## Phase 3: Performance and backends

Implement NumPy and Arrow backends, add predicate/projection pushdown, optimize joins/group-bys, and benchmark compiled kernels.

## Phase 4: Ecosystem maturity

Expand docs, examples, compatibility suites, community processes, release automation, and downstream integrations.

## Phase 5: Large-scale adoption and compatibility maturity

Focus on stability, deprecations, long-term support, interoperability guarantees, and production deployment guidance.
